# go-no-go

Skill di valutazione di idee di business e startup. Si attiva con `/go-no-go` o automaticamente quando si sottopone un'idea, un pitch, un business plan o dei numeri chiedendo un giudizio.

Flusso: inquadramento → ricerca di mercato obbligatoria (web) → assunzioni portanti falsificabili con kill-criterion → stress-test dei numeri → pre-mortem (Tiger / Paper Tiger / Elephant) → probabilità per classe di riferimento → verdetto **GO / CONDITIONAL-GO / NO-GO** con il prossimo test a più alto valore.

Richiede WebSearch/WebFetch disponibili nella sessione. Risponde nella lingua in cui è scritta l'idea.
